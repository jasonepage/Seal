## Description

```
Some things should only be opened later, by the right person.

Seal lets you write sealed letters for the people you love. A letter can hold words, photos, a voice message, and the things you never wrote down anywhere else, like passwords, account details, or where the spare key is.

YOU CHOOSE WHEN IT OPENS

- Right away: like a message in a bottle. The person you chose can open it as soon as they have it.
- Break glass: for an emergency. When enough of the people you trust use their keys together, it opens at once.
- When I go quiet: if you stop checking in for a while, Seal warns you for days first. One tap from you stops it.

NOBODY CAN OPEN IT EARLY

Not Apple. Not us. Each letter is locked on your phone before it leaves it. Only the people you chose, under the rule you chose, can open it.

SIMPLE ENOUGH FOR ANYONE

- Sign in with Face ID. No password to remember.
- Harbor, the Seal guide, always shows you the one next step.
- Opened letters can be read aloud.
- Want extra safety? Add a small security key. You can buy a ready-made kit at sealmessenger.com/give.

FAIR PRICE

Seal is free to download and try. Sealing your letters is a one-time purchase of $29.99. No subscription. Re-sealing is free forever. The people who receive your letters never pay.

OPEN SOURCE

The code is public, so anyone can check how it works.
```
